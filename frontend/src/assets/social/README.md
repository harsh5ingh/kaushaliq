# Social marks

- GitHub: official GitHub Primer Octicons `mark-github-16.svg`, https://github.com/primer/octicons (MIT; see LICENSE.github).
- LinkedIn, X and YouTube: Simple Icons 11.15.0, https://github.com/simple-icons/simple-icons/tree/11.15.0/icons (CC0-1.0; brand trademarks remain with their owners).

SVG artwork is stored locally, displayed with a CSS mask using the theme's text color. The supplied KaushalIQ PNG assets are unchanged.

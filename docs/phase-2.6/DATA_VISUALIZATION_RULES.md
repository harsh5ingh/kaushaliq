# Data visualization rules

- Every measurement must be Observed, Derived, Forecast, Scenario or Unavailable. Current verified routes contain only Observed or Unavailable. References are labelled reference-only.
- Historical rates: preserve exact percentages, population denominator, age15+, sex, rural/urban, activity definition, July–June period, source and evidence. Sort period_start ascending. 0–100 domain; no smoothing, area-volume implication, gap fill or future points. Line segments are visual guides, not additional observations.
- A single state period supports a point, not a trend claim. No arrows or change metrics are created without a defined comparable-period method.
- PLFS pre-January2025 is the current contract. New methodology responses fail closed until an explicit comparability implementation exists. Do not splice the two designs.
- Regional comparison orders published observations from matching slices. Not a quality/performance ranking. Missing regions absent from marks and named separately, never zero. Never average states to recreate India.
- PMKVY remains reported-person counts with partial-year/cohort/120-total-quarantine disclosures. Do not create composition charts, conversion rates, capacity, placements or gaps from incompatible cohorts.
- NIC partial taxonomy does not justify occupation/skill edges, job demand or workforce volumes.
- No connected geometry → no map. No evidenced relationships → no network. No model/evaluation/uncertainty → no future forecast. No compatible demand/supply units → no gap.
- Hover is supplemental. All important observations have keyboard/table/selection access to evidence. Status is text, not color alone. Both themes, languages and five viewport widths must be verified.
- Loading/error/unavailable never select a simulation provider. Production rejects legacy URL modes. No Math.random, synthetic indices or mock observation generators in verified visualization modules.

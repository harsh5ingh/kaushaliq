# Spatial intelligence decision

Current connected geography comprises India and 36 state/UT references from PLFS labels. Internal IDs are not official administrative codes. Geometry_reference and official_code remain null; district observations, geometry licence, CRS and boundary vintage are not verified. Therefore no defensible choropleth, extruded map, city pillar or spatial relationship network can be published.

`/spatial` now presents coverage, missing geographic requirements and a link to the actual state/UT dot comparison. Workspace navigation says Spatial intelligence rather than promising a connected 3D product. Relationship intelligence has an explicit unavailable state and typed evidence-bearing contract. Neither reference count nor a state percentage is repurposed as spatial intensity.

Legacy Phase 2.4 cylinders/positions/synthetic links are preserved only in development for historic regression URLs (`?data=sample`), labelled with the existing simulated disclosure. The data-mode selector and spatial simulation CTA were removed. Production DataProvider ignores sample URL parameters. All legacy lazy imports are behind build-time DEV guards; the Three.js spatial renderer and other simulated workspace chunks are absent from production output. No automatic fallback on API failure.

No new 3D renderer is implemented in this phase: data eligibility fails before renderer selection. WebGL-unavailable production tests verify the coverage experience still works; they do not claim a new GPU renderer/fallback was built. Existing development prototype fallback remains regression-tested.

Future join requires authoritative versioned/licensed geometry + declared CRS + verified geography codes + observations at matching administrative level and period. Geometry acquisition/normalization belongs to the existing canonical pipeline. Only then evaluate deck.gl/MapLibre or Three/R3F against analytical value, mobile readability and accessible 2D alternative. No guessed district values, geocoded approximate cities or arbitrary network edges. Prefer 2D when clearer.

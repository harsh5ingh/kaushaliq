# Quality, evidence and unresolved capabilities

Historical records retain existing source checksum/cell locator/transformations, original value/unit and source/publication version. Adapters fail rather than relabel ESTIMATED, DERIVED or SCENARIO records as OBSERVED. Same native classifications and source versions are required for adjacent changes. Backend DTOs reject unavailable arithmetic/predictions, missing input lineage and "available" backtests with null error metrics or leaked target IDs. Frontend rejects contradictory or invalid contracts rather than formatting null as zero.

Known source issues remain intact: national PMKVY TRAINED FY2024-25 differs by 120 from its state sum and stays quarantined; Chandigarh rural PLFS cells are absent; some NCS geography buckets are unmatched; Lakshadweep training output is absent. No reconstructed total, invented code, district downscaling or missing time point is created. Partial training observations remain explicitly partial. Source publications and raw acquisition/ingestion architecture are unchanged.

The page reuses the shared source-evidence dialog. Selected observation source/geography context is captured when opened, so filters do not relabel an existing evidence selection. API evidence retains the model window/inputs/backtests/readiness alongside original source identities. Public source DTOs contain no internal raw paths or private account identifiers. Reference labels remain source metadata rather than translated/reinterpreted classifications.

## Required evidence to unlock forecasts

- PLFS: reviewed comparable revised-design historical series, plus explicit handling/bridge for the January 2025 methodology change; otherwise keep separate regime-specific series. More points alone do not resolve comparability.
- NCS: repeated dated observations of the same administrative stock, consistent registration/coverage/geography/definition and versioned evidence. A single stock cannot establish trend, annual hiring or total demand.
- PMKVY: sufficient complete comparable fiscal-year native training-output history, quarantine/quality resolution and stable definitions. Outputs cannot stand in for current workers, training seats/capacity or vacancy-compatible supply. Partial-year extrapolation is not allowed.
- District/occupation/skill/industry: actual verified time series and reviewed geography/classification/version/mapping evidence; reference entities do not supply measurements.
- Baseline deployment: scientific review of adequacy, error tolerances, interval calibration and structural-change assumptions; future seasonal/ML models require independent evidence and comparison to the benchmark. No present prospective accuracy claim.

Phase 3 compatibility and gap readiness are unchanged (UNAVAILABLE/NOT_READY). Forecast model output cannot unlock gaps or turn incompatible supply/demand into a common population. Full Time Machine, forecasting acquisition/scheduling, early warning, AI causal narrative, scenarios and Phase 5 remain deferred.
